## Card Model

**Card type values** (from upstream): `'pokemon' | 'supporter' | 'item' | 'tool' | 'Fossil'`
- There is **no `'trainer'`** type. Always use `isTrainerCard(card)` — never `card.type === 'trainer'`.

**Card IDs**: `${set}-${number}` (e.g. `A1-7`, `PROMO-A-1`)
- Sets always uppercased. Numbers are parseInt-clean — no zero-padding.

**Card name encoding**: upstream uses curly apostrophes (U+2019), e.g. `Professor’s Research`.
- Hardcoded name lists must match exactly.

**Data sources**:
- base: `flibustier/pokemon-tcg-pocket-database/dist/cards.extra.json` — set, number, name, rarity, image, element, type, stage, health, retreatCost, weakness, evolvesFrom
- rich: `public/cards-rich.json` — attacks + abilities, generated by `scripts/fetch-rich-cards.mjs` from hugoburguete

Refresh rich data when a new TCGP set ships: `node scripts/fetch-rich-cards.mjs` → rewrites `public/cards-rich.json`. Pure Node, no deps.

## Pinned Decks

`Deck.pinnedAt?: string` (ISO timestamp; absent = unpinned).
Sort order: pinned first by `pinnedAt asc`, then unpinned by `createdAt desc`.

## DeckEditor Layout Invariant

`DeckEditor.tsx` uses `order-1 lg:order-2` on the deck panel and `order-2 lg:order-1` on the card browser.

- **Mobile (single column)**: deck panel renders first — user sees their deck immediately.
- **Desktop**: card browser sits on the left.

**Do not remove these `order-*` classes when refactoring.**

---

## Deck-Row Tap Target

Each card row in `DeckEditor.tsx` is `<div role="button" tabIndex={0}>` — **not** `<button>` — because the inner `−` remove control is itself a `<button>` and nested buttons are invalid HTML. The inner button uses `e.stopPropagation()`.

## Animation Invariants

**Score-tween + grade-pop** (`DeckAnalysis.tsx`): two `setState`-in-`useEffect` blocks wrapped in `eslint-disable react-hooks/set-state-in-effect`. Both are intentional (RAF tween + grade-pill DOM remount). Do not remove the disables.

**Sparkle / pin-halo timers** (`DeckBuilderPage.tsx`): `sparkleDeckId` and `justPinnedId` cleared after ~700–900 ms via `useEffect` timeouts. Always include the `clearTimeout` cleanup return.

---

## Scoring

`deck-scoring.ts` has 10 heuristics, each returning `HeuristicResult`. Weights sum to 1.00. `useDeckScoreTween` is a RAF hook — do not move it outside `DeckAnalysis.tsx`.

`auto-build.ts` calls `scoreDeck` as the greedy objective. `card-classifier.ts` provides strategy signals via regex on attack/ability text.

**Anthropic Vision calls**: model ID `claude-sonnet-4-6`. Browser-direct requires header `anthropic-dangerous-direct-browser-access: true`.
