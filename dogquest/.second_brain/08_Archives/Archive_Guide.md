# Archive Guide

Tags: #archive #backup

## Weekly Archive

1. Duplicate the full vault folder.
2. Rename it using ISO date format: `YYYY-MM-DD_Claude_Second_Brain_Backup`.
3. Move it somewhere Claude cannot edit.
4. Keep at least 4 weekly backups.

## Before Major Changes

Archive before:
- Large memory edits
- New project restructuring
- Importing large data sets
- Deleting or merging notes

## Restore Process

1. Locate latest good archive.
2. Compare changed files.
3. Copy back only the needed files.
4. Avoid overwriting newer valid notes.
