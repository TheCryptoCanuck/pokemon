# Red Team Final Check Prompt

Tags: #prompt #red-team

```text
Before finalizing, critique your own answer.

Check:
1. Is anything unsupported?
2. Are there missing steps?
3. Is the answer overcomplicated?
4. Is any instruction unsafe or unreliable?
5. What would fail in real execution?
6. What should be simplified?
7. Did memory bias the answer incorrectly?

Then revise the answer.
```
