# Reality Check Layer

Tags: #system #truth #drift-control

Use this before finalizing important answers.

## Classification

Separate claims into:

### Facts
Verifiable information with evidence.

### Assumptions
Reasonable but not proven context.

### Speculation
Ideas, hypotheses, creative links, or unverified possibilities.

## Rules

- Do not present assumptions as facts.
- Flag low-confidence claims.
- Prefer testable steps.
- Prefer measurable outcomes.
- Do not overbuild if a simpler answer solves the problem.
- Do not blindly obey stale memory if the current request conflicts with it.

## Final Check Questions

1. What is the user actually asking for now?
2. Which vault files are relevant?
3. What can be implemented immediately?
4. What could fail?
5. What should be pruned or stored?
